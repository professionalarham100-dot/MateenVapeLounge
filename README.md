# MateenVapeLounge — Inventory Management System

A web-based inventory management system built for a retail vape shop. Supports role-based access for owners and staff with full audit logging.

## Features
- Owner and staff role dashboards
- Product inventory tracking
- Refill service management
- Audit logging for all actions
- Deployed on Railway

## Tech Stack
- **Backend:** Flask (Python)
- **Database:** MySQL
- **Frontend:** Vanilla JS, HTML/CSS
- **Deployment:** Railway

## Setup
1. Clone the repo
2. Create `.env` from `.env.example`
3. Install dependencies: `pip install -r requirements.txt`
4. Run: `python app.py`
